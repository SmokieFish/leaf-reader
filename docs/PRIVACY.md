# 数据与联网

书籍、阅读进度、译文缓存和译名记忆存于应用私有目录。只申请 INTERNET 权限；通过系统文件选择器导入。关闭 Android 系统自动备份。

开启翻译后，手机通过 HTTPS 直接连接 `api.deepseek.com` 或 `translate.googleapis.com`。DeepSeek 会收到待译片段、有限的相邻上下文与相关术语；免费通道发送单个片段。服务提供方可能按其政策处理收到的文字。应用没有自建中转服务器、广告或分析上报代码。

v1.2 起使用 Android Keystore + AES-GCM 在本机保存 API Key；v1.0/v1.1 只在内存中持有 Key。Key 不包含在应用导出的书架备份中。

书架 JSON 备份包含书籍正文和阅读记录，是个人数据，应自行妥善保管。仓库仅包含原创示例与合成测试文件，不包含用户导入的小说或阅读数据库。

免费 Google 通道为非官方接口，可能限流或不可用。关闭翻译/切到后台会停止发起新请求；已发出的请求可能仍完成并计费。
