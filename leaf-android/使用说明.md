# 页间 Android 1.2

这是原生 Android 应用，不使用 WebView，不加载之前的网站，无需网站账号。

## 安装

在 Android 8.0 或以上设备打开 `LeafReader-Android-1.2.apk` 并安装。如系统询问，允许当前浏览器/文件管理器安装此文件。应用使用自签名开发证书，未发布到应用商店。安装后名称为“页间”。

从原生 1.0 / 1.1 升级时直接覆盖安装；包名和签名保持相同，书架、阅读位置、译文缓存和设置会保留。不要先卸载旧版。

首次安装包含一篇原创阅读指南。书架右上角“＋ 导入”可以选择书籍；长按书架上的书可从头阅读或删除。

## 功能

- 本机书架、搜索、阅读进度与按日记录的阅读历史。
- EPUB、TXT、DOCX 文字导入。文字型 PDF 导入需要 Android 15 或以上；扫描 PDF 需要先 OCR。
- 这一版采用文字排版，不保留书籍插图、复杂表格和原始 PDF 版式。
- 字体、14–32 sp 字号、行距、页边距、纸白/暖棕/浅绿/夜间背景。
- 点击屏幕右侧三分之一，或向左滑动：下一页。点击左侧三分之一，或向右滑动：上一页。
- 阅读菜单默认隐藏，点击中央三分之一显示/隐藏。菜单覆盖在正文上，不重新分页，也不会因打开菜单额外触发翻译。
- 菜单中保留章节目录、进度条跳转、翻页按钮和 10–180 秒自动翻页。长按正文可选择复制；上下滚动不会误翻页。
- 长译文可滚动；自动模式先滚完再翻页。应用切到后台、呼出菜单、打开设置或选择文字时暂停自动翻页。
- 底部“我的”页面配置 DeepSeek API Key、模型、语言和术语表，也可选择免费 Google。可勾选“打开书籍时自动开始随读随译”。阅读时单击菜单“翻译”开启/暂停，长按进入配置。
- 先翻译当前阅读页，每批最多 3 个片段。当前内容准备好后，接近读完才预译紧接着的一页；当前页未译完时不会夹带未来页面。停在同一页不会继续往后翻译。
- 长页滚动到约 70% 时预译；一屏能看完的页面，按字数、阅读速度和前台停留时间估算（最早 8 秒，最晚 90 秒）；自动翻页模式按剩余约 30% 时间触发。
- “我的 → 预译时机”可调整阅读速度，默认 400 字/分钟。应用无法知道眼睛读到哪儿，因此静态页的时机是估算；阅读偏快可调高，偏慢可调低。
- 后台、菜单、设置、选中文字或等待当前译文时不累计阅读时间，不启动新请求。已完成的译文按稳定原文片段缓存，调字号或重读不重复请求已译片段。
- 跳页时尚未发出的旧任务丢弃，已发出的请求会结束并缓存，可能已产生费用。
- 原文、优先显示缓存译文、双语对照三种显示方式。
- JSON 备份与恢复，包含书籍、译文、历史，不包含 API Key。备份格式与之前网页版本不同。

## API 与数据

在“我的 → DeepSeek API 配置”输入并保存 Key。Key 通过 Android Keystore 管理的 AES-GCM 密钥在本机加密存储，重开应用时读取；不写入普通阅读设置，不包含在书架备份中。配置页支持显示/隐藏、修改与清除 Key。如果系统无法解密，会提示重新填写。

默认模型名称为 deepseek-flash，可自行修改；使用你自己的 API 余额。请求使用非思考模式。术语表仅用于 DeepSeek。第一次从 1.1 升级需要在“我的”保存 Key，因为旧版只保存在内存。

请求由手机通过 HTTPS 直接发送到 api.deepseek.com 或 translate.googleapis.com，没有中转网页服务器。免费通道为非官方接口，可能限流或不可用。失败会暂停，需要手动重试，不会无限重试。点击正文中央呼出菜单，再点击顶部错误文字即可重试。

改通道、语言、模型或术语表会使用新的缓存；改字体、背景或字号不会。关闭随读随译后仍可显示缓存译文，需要完全显示原文时在“样式”中选择“只显示原文”。

数据保存在应用私有目录，卸载会删除，请先导出备份。单本导入文件上限 35 MB；解压内容上限 120 MB；正文上限 500 万字符。

只申请 INTERNET 权限。书籍通过 Android 系统文件选择器读取，不申请全盘存储权限。

## 验证范围

1.1 修复 Android XML 解析器的 DOCDECL 与手工实体注册冲突。用 AOSP 解析器复现了 1.0 的异常，修复后已通过实际 EPUB 导入；同时兼容文件管理器将 EPUB 标记为 ZIP、缺少显示文件名、书内路径含空格/中文及 UTF-16 章节。缺失章节会明确报错。

已通过 61 项回归检查（9 项核心分页/缓存、12 项手势、21 项按阅读进度预译、6 项加密编解码、13 项导入，包括用户提供的 EPUB：2865 个正文片段、368877 字符、36 个章节/分区），以及 Android SDK 35 编译、D8 转换、APK 对齐及 v2/v3 签名校验。导入测试使用真实 AOSP KXmlParser；测试适配器和第三方测试源码不会打进 APK。已核对与 1.0 / 1.1 的包名和签名一致、版本号递增；数据库格式保持兼容。

加密测试覆盖 AES-GCM 往返、随机 IV、篡改与错误密钥拒绝，未替代 Android Keystore 的设备测试。尚未在 Android 实机或模拟器运行，也未用真实付费 DeepSeek Key 做端到端验证。APK 属于可安装的开发测试版，仍可能有设备兼容性问题。

## 源码与重建

源码为 Java 和 Android 原生视图，不依赖网页或第三方 UI 框架。

在 Linux 环境安装 Java 17 或更高版本、Python 3 后：

```bash
python3 android-toolchain/setup.py
bash leaf-android/build.sh
bash leaf-android/sign.sh
bash leaf-android/test.sh  # 可选：传入此前的 Into the Wild.epub 路径运行原书回归测试
```

setup.py 从 Android 官方仓库下载 SDK 35 平台与 Build Tools 35.0.0，并校验官方 SHA-1；ECJ 从 Maven Central 下载。工具不包含在源码包内，首次构建需要联网。

公开仓库不包含签名私钥。签名与构建方式见仓库根目录 `docs/BUILDING.md`。

原生源码不包含你上传的小说、API Key 或阅读数据。
