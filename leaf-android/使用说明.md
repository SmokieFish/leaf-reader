# 页间 Android 1.3.1

这是原生 Android 应用，不使用 WebView，不加载之前的网站，无需网站账号。

## 安装

在 Android 8.0 或以上设备打开 `LeafReader-Android-1.3.1.apk` 并安装。如系统询问，允许当前浏览器/文件管理器安装此文件。应用使用自签名开发证书，未发布到应用商店。安装后名称为“页间”。

从原生 1.0 / 1.1 / 1.2 / 1.2.1 / 1.3 升级时直接覆盖安装；包名和签名保持相同，书架、阅读位置、译文缓存和设置会保留。不要先卸载旧版。

首次安装包含一篇原创阅读指南。书架右上角“＋ 导入”可以选择书籍；长按书架上的书可从头阅读或删除。

## 功能

- 本机书架、搜索、阅读进度与按日记录的阅读历史。
- EPUB、TXT、DOCX 文字导入。文字型 PDF 导入需要 Android 15 或以上；扫描 PDF 需要先 OCR。
- 这一版采用文字排版，不保留书籍插图、复杂表格和原始 PDF 版式。
- 字体、14–32 sp 字号、行距、页边距、纸白/暖棕/浅绿/夜间背景。
- 点击屏幕右侧三分之一，或向左滑动：下一页。点击左侧三分之一，或向右滑动：上一页。
- 阅读菜单默认隐藏，点击中央三分之一显示/隐藏。菜单覆盖在正文上，不重新分页，也不会因打开菜单额外触发翻译。
- 菜单中保留章节目录、进度条跳转、翻页按钮和 10–180 秒自动翻页。长按正文可选择复制；上下滚动不会误翻页。
- 长译文可滚动；自动模式先滚完再翻页。应用切到后台、呼出菜单、打开设置或选择文字时暂停自动翻页。
- 底部“我的”页面配置 DeepSeek API Key、模型、语言和术语表，也可选择免费 Google。可勾选“打开书籍时自动开始随读随译”。阅读时点击菜单“关闭翻译”，立即显示原文并停止新请求；点击“开启翻译”恢复译文。长按按钮进入配置。
- 先翻译当前阅读页，每批最多 3 个片段。当前页译好后，立即准备后面两页，不再等待阅读进度或停留时间。DeepSeek 预译每批最多 6 个片段，免费通道每批最多 3 个片段；当前页未译完时不会夹带未来页面。
- 翻一页就补齐前方两页。预译范围始终以正在看的页为准；停在同一页时不会越过两页范围持续调用 API。临近书尾自动缩小范围。快速跳页或网络慢时仍可能需要等译文。
- “我的 → 预译与一致性”说明预译范围与一致性机制。字号改变后按新的分页计算范围，已经译过的原文片段不会重复请求。
- 后台、菜单、设置、选中文字或关闭翻译时不启动新请求。已有译文按稳定原文片段缓存；重读直接使用缓存。
- 跳页时尚未发出的旧任务丢弃，已发出的请求会结束并缓存，可能已产生费用。
- 翻译关闭时只显示原文；开启时可在“样式 → 开启翻译时的布局”选择译文或双语对照。切换不删除缓存，后续翻页及重开书籍也会遵循开关状态。
- JSON 备份与恢复，包含书籍、译文、译名记忆、历史，不包含 API Key。备份格式与之前网页版本不同。

## API 与数据

在“我的 → DeepSeek API 配置”输入并保存 Key。Key 通过 Android Keystore 管理的 AES-GCM 密钥在本机加密存储，重开应用时读取；不写入普通阅读设置，不包含在书架备份中。配置页支持显示/隐藏、修改与清除 Key。如果系统无法解密，会提示重新填写。

默认模型名称为 deepseek-flash，可自行修改；使用你自己的 API 余额。请求使用非思考模式、temperature 0.2。术语表与上下文一致性功能仅用于 DeepSeek。第一次从 1.1 升级需要在“我的”保存 Key，因为旧版只保存在内存。

### 前后译法的一致性

DeepSeek 请求会带上紧邻当前批次的最多两段前文原文，以及这些段落已经缓存的译文；还会附带后方一小段原文帮助消除歧义。上下文与待译内容分开，只有指定原文片段会生成并保存译文。不发送整本书。前文译文每段最多 700 字符，原文每段最多 400 字符。

每本书会独立记住已采用的人名、地名和组织名（每个翻译配置最多 256 项），每次仅提供相关的最多 24 项。模型每批可建议最多 8 个新名称；只接受原文中确实出现、译文中也确实用到的名称。已有映射不会被后续模型输出覆盖。书籍或翻译配置不同，记忆相互隔离；记忆保存在本机数据库，重开应用仍可使用，书架备份也包含它。旧版本备份缺少译名数据时仍可正常恢复。

手动术语表在提示中的优先级最高。例如在“我的 → DeepSeek API 配置 → 术语表”填写 `ThunderClan = 雷族`，每行一个名称。阅读时长按“开启/关闭翻译”按钮可进入配置，查看本书自动译名的前 24 项。重要名称或发现的错误应在手动术语表中明确指定；改术语表会启用新的缓存配置，原先的译文缓存不会被删除。

**不能保证 100% 一致。** 自动名称识别、指代和文风仍可能出错，提示约束也不等同于逐字强制替换。旧缓存会保留；升级不会为了新策略自动重新翻译已经付费生成的页面。记忆只对新处理的片段逐步建立，不会额外扫描翻译整本书。短上下文与名称表会增加输入用量。免费 Google 通道仍是逐片段翻译，支持提前两页，但不具备上述上下文和术语约束。

请求由手机通过 HTTPS 直接发送到 api.deepseek.com 或 translate.googleapis.com，没有中转网页服务器。免费通道为非官方接口，可能限流或不可用。失败会暂停，需要手动重试，不会无限重试。点击正文中央呼出菜单，再点击顶部错误文字即可重试。

改通道、语言、模型或术语表会使用新的缓存；改字体、背景或字号不会。关闭翻译后立即显示原文，同时关闭“打开书籍时自动翻译”。正在处理的请求可能仍会完成并计费，其结果只保存到缓存，不会把原文切回译文。再次开启会优先使用缓存，并恢复自动翻译偏好。原文位置仍在当前页。

数据保存在应用私有目录，卸载会删除，请先导出备份。单本导入文件上限 35 MB；解压内容上限 120 MB；正文上限 500 万字符。

只申请 INTERNET 权限。书籍通过 Android 系统文件选择器读取，不申请全盘存储权限。

## 1.3.1 完整性修复

恢复备份前会先校验全部记录，再更新书架和阅读位置。不同正文不能复用同一书籍编号；越界位置、重复记录和不完整译文会明确报错。公开源码不包含签名私钥，详见仓库根目录的构建文档。

## 验证范围

1.3.1 增加 14 项备份验证测试，合成测试 109 项通过，另以用户自行提供且不进入仓库的 EPUB 验证导入，共 110 项。

1.3 已通过 96 项自动检查：9 项核心分页/缓存、12 项手势、8 项原文/译文显示、15 项提前两页调度、27 项上下文/译名/响应校验、6 项加密编解码、13 项导入及 6 项 SQLite 迁移检查。包括用用户提供的 EPUB 验证实际导入：2865 个正文片段、368877 字符、36 个章节/分区。导入测试使用真实 AOSP KXmlParser。

迁移检查在 SQLite 上执行应用实际使用的新增表 SQL，验证已有书架、阅读位置、译文与历史保留，名称记忆隔离与重开后持久化；它不替代 Android SQLiteOpenHelper 的设备测试。数据库从版本 1 追加升级到版本 2，不删除旧表。

已通过 Android SDK 35 编译、D8 转换、APK 对齐及 v2/v3 签名校验；包名与签名保持一致，应用 versionCode 递增到 6。测试适配器、测试库和第三方测试源码不会打进 APK。

尚未在 Android 实机或模拟器运行，也未用真实付费 DeepSeek Key 做端到端验证。网络翻译速度、实际模型译法和设备兼容性仍需实际使用确认。加密测试验证 AES-GCM 编解码，未替代 Android Keystore 的设备测试。

## 源码与重建

源码为 Java 和 Android 原生视图，不依赖网页或第三方 UI 框架。

在 Linux 环境安装 Java 17 或更高版本、Python 3 后：

```bash
python3 android-toolchain/setup.py
bash leaf-android/build.sh
bash leaf-android/sign.sh
bash leaf-android/test.sh  # 可选：传入此前的 Into the Wild.epub 路径运行原书回归测试
```

setup.py 从 Android 官方仓库下载 SDK 35 平台与 Build Tools 35.0.0，并校验官方 SHA-1；ECJ 从 Maven Central 下载。工具不包含在源码包内，首次构建需要联网。

公开仓库不包含签名私钥。签名与构建方式见仓库根目录 `docs/BUILDING.md`。

原生源码不包含你上传的小说、API Key 或阅读数据。
